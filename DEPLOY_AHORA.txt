⚠️ REQUISITOS PREVIOS:

  • DNS de robotics.edumind.es debe apuntar a este servidor
  • Puerto 80 abierto en firewall

  → ollama list    (debe mostrar: phi3:latest)

═══════════════════════════════════════════════════════════════

📝 VER LOGS:

  Backend:
  → sudo journalctl -u edumind-robotics -f

  Nginx:
  → sudo tail -f /var/log/nginx/access.log
  → sudo tail -f /var/log/nginx/error.log

═══════════════════════════════════════════════════════════════

🔧 COMANDOS ÚTILES:

  Reiniciar backend:
  → sudo systemctl restart edumind-robotics

  Reiniciar Nginx:
  → sudo systemctl reload nginx

  Ver estado:
  → sudo systemctl status edumind-robotics
